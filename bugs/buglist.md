## 🔍 Подробные карточки активных инцидентов

### BUG-001: Не работает Drag & Drop файлов в окно программы
- **Симптом:** Пользователь перетаскивает файл или папку на окно, но ничего не происходит, путь не подставляется.
- **Root Cause:** В WebView2 / Chromium объект `File` в стандартном DOM-событии `ondrop` не содержит системного абсолютного пути (`file.path === undefined`). В Tauri v2 нативный перехват событий Drag & Drop блокирует DOM-события и требует подписки через `getCurrentWebview().onDragDropEvent(...)` или `getCurrentWindow().onDragDropEvent(...)`. Дополнительно при запуске приложения под правами администратора Windows UIPI блокирует сообщения drag-drop от неэлевативного explorer.exe.
- **Решение:** Подключён `getCurrentWebview().onDragDropEvent` в `App.svelte` с неоновой подсветкой зоны перетаскивания и немедленным запуском инспекции. В `lib.rs` добавлены вызовы `ChangeWindowMessageFilterEx` для `WM_DROPFILES`, `WM_COPYDATA` и `0x0049`.

### BUG-002: Фантомный пустой значок рядом с основным в системном трее
- **Симптом:** В трее Windows отображается два значка FreeIt: один пустой/невидимый, второй — с ключом.
- **Root Cause:** Трей был одновременно объявлен в конфигурации `tauri.conf.json` (`trayIcon: { ... }`) и повторно создан вручную в `src-tauri/src/lib.rs` через `TrayIconBuilder::new().build(app)`. Второй экземпляр не имел установленной иконки и создавал прозрачный артефакт в трее.
- **Решение:** Удалена секция `trayIcon` из `tauri.conf.json`. Реализован единый модуль `src-tauri/src/tray.rs` по образцу `minibin_new` и `PolyShift`: `TrayIconBuilder::with_id("main_tray")` с белой монохромной иконкой, меню и нативным позиционированием `position_flyout`.

### BUG-003: Цвет и стиль иконки в системном трее при тёмной теме Windows
- **Симптом:** При тёмной теме оформления Windows иконка ключа отображается в цвете циан (`#00BCD4`), выбиваясь из нативного монохромного стиля системного трея (где все иконки белые).
- **Root Cause:** Иконка `32x32.png` была отрендерена в бирюзовом цвете бренда без адаптации под светлую/тёмную тему панели задач Windows 10/11.
- **Решение:** Подготовлена монохромная белая иконка `tray-white-32.png` (`#FFFFFF`) для нативного отображения в тёмной теме Windows. Добавлена настройка стиля иконки (Белая нативная / Фирменный циан).

### BUG-004: Отсутствие раздела/окна настроек приложения
- **Симптом:** В интерфейсе нет кнопки или вкладки настроек, невозможно указать API-ключ Gemini, выбрать модель или настроить автозапуск.
- **Root Cause:** В первичной реализации UI был свёрстан только базовый инспектор путей.
- **Решение:** Реализован компонент `Settings.svelte` и бэкенд `engine/settings.rs`: ввод Gemini API Key (с синхронизацией в `HKCU\Software\KobaltTools\API` для бесшовной синергии с PolyShift), выбор модели ИИ, автозапуск с Windows (`HKCU\...\Run`), опции Safe Vault и закрытия при потере фокуса.
