## 📝 Записи журналов

### [2026-09-12 21:48] Фиксация инцидентов BUG-001..BUG-004
- Пользователь сообщил о 4 критических дефектах поведения приложения:
  1. `BUG-001`: Файлы не перетаскиваются в окно программы (drag-and-drop не работает).
  2. `BUG-002`: В системном трее виден лишний пустой/фантомный значок рядом со значком ключа.
  3. `BUG-003`: Цвет значка в трее циан при темной теме Windows (нет гармонии со стандартным белым треем).
  4. `BUG-004`: В окне программы отсутствуют настройки (ключ Gemini API, реестр, автозапуск).
### [2026-09-12 21:58] Устранение дефектов BUG-001..BUG-004
- **BUG-001 (Drag & Drop):**
  - Подключён нативный слушатель `getCurrentWebview().onDragDropEvent` в `App.svelte` вместо неработающего браузерного `ondrop`.
  - Добавлена интерактивная визуальная зона перетаскивания (neon cyan glow при `isDragging`).
  - В `src-tauri/src/lib.rs` добавлены вызовы Win32 `ChangeWindowMessageFilterEx` для гарантированной работы D&D даже при запуске под правами администратора.
- **BUG-002 (Двойной значок в трее):**
  - Удалена секция `trayIcon` из `tauri.conf.json`.
  - Создан единый централизованный модуль `src-tauri/src/tray.rs` с `TrayIconBuilder::with_id("main_tray")`.
- **BUG-003 (Адаптивный стиль иконки):**
  - Сгенерирована белая монохромная иконка `src-tauri/icons/tray-white-32.png` (`#FFFFFF`), нативно вписывающаяся в тёмную тему Windows 10/11 (по эталону `minibin_new`).
  - Добавлена опция переключения на фирменный циан в настройках.
- **BUG-004 (Раздел настроек):**
  - Разработан Svelte 5 компонент `src/lib/Settings.svelte` в стиле Fluent Acrylic с вкладками и плавной навигацией.
  - Реализован бэкенд `src-tauri/src/engine/settings.rs`: сохранение настроек в `%APPDATA%\Kobalt\FreeIt\settings.json`, синхронизация общего ключа Gemini в реестре `HKCU\Software\KobaltTools\API` (для связи с PolyShift), автозапуск в `HKCU\...\Run`.
  - Реализована функция завершения процесса `kill_process` прямо из карточки инспектора дескрипторов.
- **Верификация:**
  - `npm run build` — фронтенд собран успешно за 606ms.
  - `cargo test --manifest-path src-tauri/Cargo.toml` — юнит-тесты ядра Restart Manager пройдены (1 passed, 0 failed).
